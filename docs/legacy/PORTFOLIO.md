# Cooking Star

## 프로젝트 개요

Cooking Star는 사용자가 직접 레시피와 요리 기록을 등록하고, 다른 사용자의 콘텐츠를 탐색하며 소통할 수 있는 요리 커뮤니티 웹 서비스입니다. 레시피 게시, 이미지 업로드, 좋아요, 북마크, 팔로우 같은 커뮤니티 기능을 중심으로 구성했으며, 네이버 검색 API, 카카오 로컬 API, Gemini API를 연동해 레시피 탐색과 메뉴 추천 경험을 확장했습니다.

## 개발 배경

기존 레시피 서비스는 단순히 레시피를 조회하는 데 그치는 경우가 많다고 판단했습니다. Cooking Star는 사용자가 직접 만든 요리 기록을 남기고, 다른 사용자의 레시피를 참고하며, 필요한 재료나 주변 맛집까지 함께 탐색할 수 있는 통합형 요리 서비스를 목표로 개발했습니다.

## 주요 기능

- 회원가입, 로그인, 로그아웃, remember-me 기반 인증 처리
- 회원 프로필 이미지 등록 및 수정
- 레시피 등록, 목록 조회, 상세 조회, 수정, 삭제
- 레시피 이미지 파일 업로드 및 삭제
- 나만의 요리 기록 등록, 수정, 삭제
- 좋아요, 댓글, 북마크, 팔로우 기능
- 네이버 블로그 검색 API를 활용한 레시피 관련 검색
- 네이버 쇼핑 검색 API를 활용한 상품 검색 및 장바구니 연계
- 카카오 로컬 API를 활용한 맛집 검색 및 저장
- Gemini API를 활용한 식사 시간별 메뉴 추천
- 관리자 페이지를 통한 회원 및 레시피 관리

## 기술 스택

- Backend: Java 21, Spring Boot, Spring MVC
- Security: Spring Security
- Database: PostgreSQL
- Persistence: MyBatis
- View: JSP, JSTL
- Build: Gradle
- External API: Naver Search API, Kakao Local API, Gemini API

## 핵심 구현 내용

### 레시피 관리

레시피 등록, 수정, 삭제, 조회 기능을 구현했습니다. 레시피 작성 시 여러 이미지 파일을 함께 업로드할 수 있도록 처리했으며, 수정 시 새 파일 추가와 기존 파일 삭제가 가능하도록 구성했습니다. 삭제 기능에서는 DB 데이터와 실제 업로드 파일이 함께 정리되도록 서비스 계층에서 흐름을 관리했습니다.

### 나만의 요리 기록

사용자가 직접 만든 요리를 기록할 수 있는 기능을 구현했습니다. 요리 기록에는 이미지가 필수로 포함되도록 검증했으며, 수정 시 기존 이미지 개수와 삭제 예정 이미지, 새로 추가되는 이미지를 계산해 최대 업로드 개수를 제한했습니다.

### 회원 인증 및 권한 관리

Spring Security를 사용해 로그인, 로그아웃, remember-me 인증을 구성했습니다. 회원가입 시 비밀번호를 암호화하고 기본 권한을 부여했으며, 관리자와 매니저 권한에 따라 접근 가능한 URL을 분리했습니다.

### 외부 API 연동

네이버 검색 API를 활용해 블로그 검색과 쇼핑 검색 기능을 구현했습니다. 쇼핑 검색 결과는 JSON 응답을 파싱해 상품명, 가격, 이미지 정보를 서비스에서 가공했습니다. 카카오 로컬 API를 활용한 맛집 검색에서는 사용자가 이미 저장한 맛집과 검색 결과를 비교해 저장 여부를 표시했습니다.

### 사용자 상호작용

좋아요, 북마크, 팔로우 기능을 구현해 사용자 간 상호작용이 가능하도록 했습니다. 좋아요 기능은 토글 방식으로 동작하며, 좋아요 등록/해제와 카운트 증감을 하나의 흐름으로 처리했습니다. 북마크 기능은 본인 레시피 북마크와 중복 북마크를 방지하도록 구성했습니다.

## 문제 해결 경험

- 게시글 삭제 시 DB 데이터만 삭제되고 실제 파일이 남을 수 있는 문제를 고려해, 삭제 전 파일 정보를 조회한 뒤 DB 삭제 성공 시 실제 파일까지 삭제하도록 처리했습니다.
- 요리 기록 수정 시 이미지 개수가 제한을 초과할 수 있는 문제를 방지하기 위해 기존 파일 수, 삭제 파일 수, 신규 파일 수를 계산하는 검증 로직을 추가했습니다.
- 외부 API 검색 결과와 사용자의 저장 데이터를 비교해야 하는 상황에서, 저장된 URL을 Set으로 관리해 검색 결과의 저장 여부를 효율적으로 표시했습니다.

## 프로젝트를 통해 배운 점

Spring MVC 기반 웹 애플리케이션에서 Controller, Service, Mapper의 역할을 분리해 기능을 구현하는 경험을 쌓았습니다. 또한 파일 업로드, 인증/인가, 외부 API 연동, 사용자 상호작용 기능을 함께 다루면서 단순 CRUD를 넘어 실제 서비스에 가까운 흐름을 설계하고 구현하는 방법을 익혔습니다.
